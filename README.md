# Mira Sen Interiors — Independent Concept Site

A fictional, pitch-ready interior designer website concept built with Next.js App Router.

## Demo details

- Designer: Mira Sen Interiors
- Location: New Delhi · Greater Kailash
- Work: homes, renovations & intimate commercial spaces
- WhatsApp: +91 96548 01993
- Instagram: @copywrk
- Concept brand: Copywrk

## Run locally on Windows

```powershell
npm install
npm run dev
```

Open http://localhost:3000.

## Customize

Edit `lib/content.ts` for the designer name, city, WhatsApp number, Instagram, project copy, materials and quiz content.

Replace the supplied concept SVGs in `public/images` with the designer's actual photographs. Keep the filenames or update the corresponding paths in `lib/content.ts`.

## Build

```powershell
npm run build
npm run start
```

## Deploy to Vercel

```powershell
npm i -g vercel
vercel
```

For production:

```powershell
vercel --prod
```

This is an independent concept website. It is not the official website of Mira Sen Interiors. Project names/details are fictional placeholders.
